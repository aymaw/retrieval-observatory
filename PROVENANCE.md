# Provenance and scope

New original, AI-assisted personal portfolio work created in November 2026.
This is not historical research software, employer source, or a deployed product.
All task data are generated synthetically from the included code; no PHI,
private records, proprietary models, scraped datasets or credentials are used.
No pretrained weights, API keys or paid services are required.

The algorithms are independent educational implementations of the cited methods,
not reproductions of published benchmark numbers. Standard third-party libraries
retain their own licenses; MIT covers this original code and generated fixtures.
Reports in `results/` are from executed commands recorded in `results/run.json`.
The browser demo replays those outputs; it does not run Python training in JavaScript.
Performance is limited to the documented toy distribution. Report runtime and
environment describe the measured host, not a portable speed guarantee.
